# SoroDev

A trilingual personal portfolio for Soroush Salehi.

## Features

- Persian, English and Russian language switching
- Automatic RTL/LTR layout direction
- Responsive layout for desktop, tablet and mobile
- Lightweight 2D motion and scroll reveal effects
- Dark and light themes with saved preferences
- Reduced-motion accessibility support
- No framework, build step or 3D dependencies

## Stack

HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve the folder with PHP:

```bash
php -S 127.0.0.1:8000
```

Then visit http://127.0.0.1:8000.
